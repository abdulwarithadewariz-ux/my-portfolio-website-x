Dopamind

An AI-powered study studio.

A study command centre that turns scattered notes and PDFs into active recall — AI-generated flashcards and quizzes, a focus timer with XP, and study groups you can invite friends to.

View source Live site — not deployed
Dopamind.Concept preview — no public running build to screenshot

01 — The problemStudying is passive, so it doesn't stick

Most students re-read notes and call it revision. But re-reading feels productive while doing almost nothing for recall. The tools that actually work — active recall, spaced repetition, focused timed sessions — are scattered across different apps, and none of them talk to your own notes.

Dopamind's idea: turn your own material into an active study system automatically, so the friction of making flashcards and quizzes disappears.

02 — The solutionYour content, turned into recall

Dopamind is a Flask web app with a dark, focused interface. You add courses and drop in material — pasted text, PDFs or YouTube transcripts — and it extracts the content into a source notebook. From there, an LLM generates flashcards and quizzes grounded in your material rather than generic textbook questions.

  • AI flashcards & quizzes generated from your own uploaded content.
  • Source notebook — PDF text extraction and YouTube transcript ingestion.
  • Focus timer with XP and a leaderboard to make sessions additive.
  • Study groups with invite codes, plus notes and task tracking.
  • Streaming AI chat for asking questions about your material.

03 — Who it's for

Students — particularly university students — who want to revise actively instead of passively re-reading. It suits anyone revising from their own lecture notes, PDFs and recorded lectures rather than a fixed commercial syllabus.

06 — Challenges

  • Grounding generation in real material. The hard part wasn't calling an LLM — it was extracting usable text from PDFs and transcripts and feeding it in so the generated questions actually matched the student's content.
  • Honest scope. This is a functional prototype, not a hardened product. The README states plainly that it's dev-server only, uses basic password hashing and has no rate limiting — I'd fix all three before any real deployment.

07 — Status & next

Dopamind is a working local prototype, and its source is public on GitHub. It is not deployed, and I don't want to imply otherwise. Before it could go live I'd replace the password hashing, add rate limiting, wire up real payments and add spaced-repetition scheduling — which is also the feature that would most improve learning outcomes.
